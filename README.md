# HTML & CSS Small Projects

A collection of 10 beginner-friendly projects to practice HTML and CSS fundamentals.

## Projects

### 01. Personal Profile Card

- Profile image
- Name and bio
- Social links
- Card styling

### 02. Product Card

- Product image
- Product name
- Price
- Rating
- Add to Cart button

### 03. Login Form

- Email input
- Password input
- Remember me checkbox
- Login button

### 04. Restaurant Menu

- Restaurant name
- Menu categories
- Food items
- Prices

### 05. Pricing Cards

- Starter plan
- Pro plan
- Business plan
- Features list
- CTA buttons

### 06. Landing Page

- Navigation bar
- Hero section
- Heading and description
- CTA button
- Image
- Additional content section

### 07. Blog Article

- Article title
- Author information
- Date
- Featured image
- Article content

### 08. Weather Card

- City
- Temperature
- Weather icon
- Humidity
- Wind speed

> Static data only. No JavaScript required.

### 09. Portfolio Hero

- Developer name
- Introduction
- Profile image
- View Projects button
- Contact button

### 10. Responsive Dashboard

- Sidebar
- Navigation
- Statistics cards
- Recent activity
- Responsive mobile layout

## Learning Goals

By completing these projects, you will practice:

- HTML structure
- Semantic HTML
- CSS selectors
- Box Model
- Typography
- Colors
- Flexbox
- CSS Grid
- Forms
- Buttons
- Hover effects
- Responsive design
- Media queries

## Requirements

- HTML
- CSS
- VS Code
- Web browser

No frameworks or libraries required.

## Recommended Order

1. Personal Profile Card

## Goal

Build each project from scratch using only HTML and CSS.

Focus on understanding **why** the code works instead of simply copying it.
